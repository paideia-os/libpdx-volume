# libpdx-volume v1.1.0 — release manifest (source form)
#
# This is the human-readable source form of `manifest.pdxsig`. The
# release tool at pkgs.paideia-os mirror-push time (a) enumerates the
# artifact list below, (b) recomputes every BLAKE3-256 hash from the
# repo tree at the v1.0.0 tag, (c) writes the completed manifest into
# a binary `manifest.pdxsig`, and (d) invokes
#   paideia-pq-sign::sign_release_artifact(sk, manifest_path)
# once with the paideia-release-line Ed25519 secret key and once with
# the ML-DSA-65 secret key. The two detached signatures are appended
# to the manifest in the fixed layout below and the resulting
# `manifest.pdxsig` is pushed to
#   https://pkgs.paideia-os/main/libpdx-volume/1.0.0/manifest.pdxsig
# alongside the compiled artifacts.
#
# Format mirrors `libpdx-audit`'s `release/manifest.pdxsig.txt`
# (this org's other satellite library, first through M5) byte-for-byte
# in structure — see that file for the worked template this one
# follows. Every `<BLAKE3-*>` / `<...-KID-*>` / `<...-SIG-*>` slot below
# is a placeholder the release tool fills in from the working tree at
# tag time; NONE are computed by this milestone (see
# `design/architecture.md` §10 for why signing is out of scope here).
#
# Reference:
#   design/paideia-as/v0.20-issue-1025-pq-signing.md         — Hybrid,
#     sign_release_artifact, HybridSignature (Ed25519 || ML-DSA-65).
#   design/02-development-environment.md §1140                — hybrid
#     release-artifact signature rationale (Ed25519 + ML-DSA-65).
#   design/tooling/plan.md §6.3                               — package
#     repository layout, `manifest.pdxsig` per version directory.
#   design/tooling/volume-tooling-ux.md §9.4 (paideia-os)     — M5-001
#     scope (dual-signed release + .pdxdoc + mirror push) for this repo.

# ---------------------------------------------------------------
# Signature block — dual-signed per design/02-development-environment.md
# §1140 (hybrid Ed25519 + ML-DSA-65). Both signatures cover the SAME
# canonical byte-stream: the manifest body above (everything before
# the [signatures] marker line) hashed with BLAKE3-256 and signed via
# paideia-pq-sign::sign_release_artifact. Verification is AND-semantics:
# both signatures MUST verify; failure of either rejects the package.
#
# NOT PERFORMED AT THIS MILESTONE. The paideia-as `mldsa65_sign`
# intrinsic requires a live 32-byte ML-DSA-65 seed key, and this repo
# holds no such key material (by the same zero-private-key-material
# discipline `design/architecture.md` §8.2 documents for
# `pdxb_sign_superblock`'s own `seed_ptr` argument — a signing seed is
# release-line custody, never repo-resident). The signature block below
# is left as the documented placeholder value
# `SIGNATURE_PLACEHOLDER_PENDING_LIVE_SIGN` in every slot the real
# dual-sign pass would fill; see design/architecture.md §10 for the
# full rationale and the flag for main.
# ---------------------------------------------------------------
